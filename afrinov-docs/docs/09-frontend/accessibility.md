# Accessibility

- All interactive controls keyboard-navigable and screen-reader labelled,
  since shop-floor terminals may be shared/kiosk-style devices.
- Sufficient colour contrast and non-colour status indicators (e.g. a
  low-stock flag should not rely on colour alone — pair with an icon/label),
  since workshop lighting conditions can be poor.
- Form validation errors announced, not just shown visually.
