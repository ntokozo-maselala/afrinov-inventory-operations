# Monitoring

Track: request latency/error rate per endpoint; count of failed
INSUFFICIENT_BALANCE attempts (stock-out proxy); count of materials
currently below `required_stock`; count of ad hoc (non-PO) goods receipts
(visibility into how much buying stays informal even after the system
exists). These business metrics matter as much as infrastructure health
here, since the whole point of the project is operational visibility that
didn't exist before.
